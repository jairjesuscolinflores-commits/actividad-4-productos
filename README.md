# Actividad 4 - API de Gestión de Productos

## Instrucciones para ejecutar la aplicación

1. Clonar el repositorio:
   `git clone https://github.com/jairjesuscolinflores-commits/actividad-4-productos.git`
2. Instalar las dependencias:
   `npm install`
3. Crear un archivo `.env` en la raíz con las siguientes variables:

#PORT=3000
MONGO_URI=tu_enlace_de_mongodb
JWT_SECRET=tu_clave_secreta

4. Ejecutar el servidor en modo desarrollo:
`npm run dev`
5. Ejecutar las pruebas unitarias:
`npm test`
